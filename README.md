# 🌸 SheCan NGO Website – Empowering Women

A simple and responsive NGO website created for **SheCan Foundation**, focused on empowering women by promoting education, opportunities, skill development, and social impact initiatives.

## 📌 About the Project

The **SheCan NGO Website** is designed to create awareness and provide an online presence for the organization. The website highlights the mission of empowering women and encouraging community participation.

The webpage includes:

- NGO Name
- Hero Heading
- About Section
- Empowering Women Image
- Call-to-Action Button
- Footer Section
